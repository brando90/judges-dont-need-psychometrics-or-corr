# Technical memo, 11-25-2026: cross-entropy, not correlation, for AI judges

**Doc link:** <https://github.com/brando90/judges-dont-need-psychometrics-or-corr/blob/main/paper_latex_and_notes/ICML_format_tech_memo_11-25-2026/README.md>

**TLDR:** One ICML-format memo that consolidates the results of every experiment folder in this repository (00 to 31, archived 11 to 14 included): main text, references, then appendices with the proofs, the protocols, an index of all experiments, extra tables and figures, and provenance. `memo_11-25-2026.pdf` is the compiled memo and `HANDOFF_STANFORD_LIBRARY_11-25-2026.md` holds what a depositor needs. It is built from repository commit `64d6abe`. It has not been deposited in the Stanford Digital Repository; that is a human step.

**Title:** Learn Judges Like Any Other Model: Cross-Entropy, Not Correlation, for Predicting Human Rating Distributions. Brando Miranda, Stanford University. 11-25-2026.

## Files

- `memo_11-25-2026.pdf`: compiled memo (ICML 2026 style, preprint option). Main text through the recommendations, then references, then Appendices A to E.
- `memo_11-25-2026.tex`, `sections/`: LaTeX source. `01`–`08` are the main text; `A_proofs` (derivations and the exact counterexample), `B_protocols` (metric definitions, protocols, how each judge was chosen), `C_index` (every experiment, its question and headline result), `D_extra` (details, tables and figures behind the main text), `E_provenance` (reproduction and data handling).
- `figures/`, `tables/`: generated by `make_memo_assets.py` from committed result files of experiments 24, 25, 26, 28, 29 and 31 and the figure that experiment 08 printed for the AAAI paper folder, plus the exact rational arithmetic of the three-item counterexample (experiment 27). Nothing is typed by hand.
- `assets_log.txt`: the values the script printed for the figures and tables.
- `memo_refs.bib`, `icml2026.sty`, `icml2026.bst` and the helper style files: bibliography and ICML kit.
- `check_numbers.py`: checks that every decimal, and every integer of 100 or more, in a memo sentence appears together with the rest of that sentence's numbers in one report file of this repository. It checks that the numbers exist, not that the sentence draws the right conclusion from them.
- `HANDOFF_STANFORD_LIBRARY_11-25-2026.md`: title, abstract, keywords, license, file hashes and the open decisions for the deposit.

## Build and check

From this directory:

```bash
make                                   # python3 -I make_memo_assets.py, then latexmk -pdf (pdflatex + bibtex)
cd ../.. && python3 -I paper_latex_and_notes/ICML_format_tech_memo_11-25-2026/check_numbers.py
```

The build needs only committed files. It makes no model calls and costs nothing. Aux files are gitignored; the PDF is committed with any change to the source.

The standalone source archive (this folder without the repository) rebuilds the PDF with `make pdf`, using the figures and tables it contains. Regenerating those, and `check_numbers.py`, need the repository at the commit named above.

## How to read the numbers

Every reported number follows this repository's reporting rule: the data (train, validation or held-out test), the metric with its definition and direction, what a difference subtracts from what, the interval and how the judge was chosen. Differences are written as "test RPS of the Pearson-trained judge minus test RPS of the CE-trained judge; positive means the CE-trained judge is better". Appendix B states the metric definitions and protocols; each experiment folder has its own `HOW_TO_READ_RESULTS.md`.
