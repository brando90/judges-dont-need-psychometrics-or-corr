**Training procedure.** Independently within each of the two May pools, generate 200 fixed training orders using NumPy SeedSequence([20261121, pool index, draw index]), pool index 0 for strict and 1 for broader. Within each historical family, randomly permute its artifacts, then traverse the families in a newly permuted order for each pass and take one remaining artifact per family. For every selected artifact, permute its available expert rating slots without replacement. Each budget uses the corresponding nested prefix of artifacts. The one-rating condition uses the first slot and the two-rating condition the first two. Both models and both objectives use identical draws. With fixed seed and the input digest, all training selections can be reproduced. Repeated draws are for averaging the procedure’s performance, not additional humans.

Apply the shared 27-transform grid, cross-entropy and Pearson selectors, identity-first tie handling, and six-category 1e−6 floor in the parent protocol. Each objective exhaustively selects one head using only the designated training ratings, equally weighting artifacts. The denominator for Pearson is the association across artifacts between model means and observed artifact mean ratings. Completely undefined Pearson selects identity. Also save the uniform baseline, uncalibrated smoothed judge and a training histogram with 0.5 added to each category. The grid and all hyperparameters are fixed. No Set N outcome can change selection, calibration, forecasts or missing-data policy. The records include each head’s transformed probabilities for each test case and every draw’s selections and train-only histogram. This lossless representation recovers each individual predictive distribution without storing a redundant array. Keep supervised artifacts containing training histograms in restricted storage, and publish hashes and aggregate counts.

**Future scoring.** Use only a collection-owner released, adjudicated primary roster and independent numeric ratings, validated against stable item IDs and exact candidate SHA-256. Retain eligible singletons and count unique raters on every artifact. Use one mean loss per artifact (first average over that artifact’s ratings), then weight observed artifacts equally, then average the 200 draw-specific losses. Evaluate the unaveraged forecasts before averaging losses; averaging probabilities would define a different ensemble. Normalized individual-rating ranked probability score (RPS, 0–1, lower is better) is primary. Cross-entropy (natural-log units) and total variation distance to the empirical artifact histogram (0–1) are secondary. Pearson and tie-aware Spearman of expected and observed mean ratings are descriptive; report undefined values. Include original, training histogram and uniform scores. For all three panels report, at each feasible budget, comparator test RPS minus CE-fitted test RPS for Pearson, uniform, identity and histogram. Positive favors the CE fit. Report the same paired comparison on secondary losses. Report scheduled/evaluable artifacts and covered groups and raters. For incomplete panels the RPS difference on the full scheduled set is bounded by allowing each missing artifact a difference anywhere in [−1,+1]. Pointwise 95% percentile intervals use 10,000 matched resamples of entire observed operation groups (seed 20261122), holding these precomputed fits and participating raters fixed. The two heap-sort variants share one group. These are conditional descriptive intervals, with no familywise claim or finite-sample coverage guarantee. Report empty panels as unavailable. No labels means no observed test metrics, tests, or winner.
