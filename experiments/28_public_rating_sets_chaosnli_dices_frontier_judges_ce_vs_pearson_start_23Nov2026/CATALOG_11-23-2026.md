## Discrepancies found between a source's own description and its files

- DICES-990 has 172 raters in the file (README says 173) and 69 to 76 ratings per item (README says 60-70).
- KonIQ-10k has 93 to 157 votes per image (median 106), the paper says "at least 120".
- CIFAR-10H: counts file totals 511,000 decisions with 16 annotators removed (paper: 511,400 and 14 removed); README column name and trial range differ from the file.
- WMT MQM newstest2021 en-de: 17 system labels in the file (README: 15).
- oasst1: 15,044 distinct author ids (abstract: over 13,500 volunteers).
- WebGPT: 19,578 comparisons released (paper: about 21,500 collected); the released score has 9 distinct values although the paper describes a 5-point scale.
- Chatbot Arena card cites arXiv 2306.05685; the later 2403.04132 paper only promises a larger release.
