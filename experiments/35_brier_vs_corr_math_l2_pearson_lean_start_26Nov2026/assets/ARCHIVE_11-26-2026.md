## Recipient and how to open it

The archive is encrypted with [age](https://age-encryption.org) to this X25519 recipient:

```text
age1f8xthff84x0x7rzed7auu5en64ug0wzz6z2awagsyulq9t8wzqyskdf8p9
```

The project owner's SSH public key could not be retrieved in this session, so this is a stopgap key. The matching identity file, `age_identity_11-26-2026.txt`, is stored only in the restricted Drive folder above and is not in this repository. With that file saved next to the archive, from this directory:

```sh
age --decrypt --identity age_identity_11-26-2026.txt private_notebook_transcript_and_plan_11-26-2026.tar.gz.age | tar -tzf -
mkdir -p private_11-26-2026
age --decrypt --identity age_identity_11-26-2026.txt private_notebook_transcript_and_plan_11-26-2026.tar.gz.age | tar -xzf - -C private_11-26-2026
sha256sum private_11-26-2026/*
```

To re-encrypt to an SSH key, decrypt as above and pipe the tar stream into `age -R ~/.ssh/id_ed25519.pub -o <new file>.age`. Anyone holding the identity can read the archive, so do not copy the identity file into this repository. Protection applies only to the files stored inside the archive; this record and its hashes are public.
