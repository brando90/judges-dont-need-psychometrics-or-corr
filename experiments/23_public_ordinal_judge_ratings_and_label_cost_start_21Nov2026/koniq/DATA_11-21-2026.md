# KonIQ-10k image-quality votes and predictors | 11-21-2026

As of 11-21-2026, the source audit found **1,078,154 released grades on 10,073 photographs**. Each of the five columns counts individual crowd votes that an image’s technical quality was bad (1), poor (2), fair (3), good (4) or excellent (5). The target is the distribution of these votes for an image. The source tables preserve vote multiplicity but omit individual worker IDs. An image-level split can measure generalization to other photographs in this collection. It cannot establish generalization to new photographers or raters. [Data release](https://doi.org/10.18419/DARUS-2435) · [Study and rating instructions](https://arxiv.org/pdf/1910.06180)

The adapter joins the DaRUS v1.0 counts and indicators to the authors’ fixed split by Flickr image ID. Each ID occurs exactly once in each table. It checks every total, reconstructs each raw mean opinion score (MOS) from integer counts, and checks the category proportions in the authors’ separate split file. The split file supplies normalized proportions and a transformed MOS. The count table supplies the original five integer counts. [Original counts](https://darus.uni-stuttgart.de/api/access/datafile/72288?format=original) · [Original indicators](https://darus.uni-stuttgart.de/api/access/datafile/72287?format=original) · [Authors’ split file](https://github.com/subpic/koniq/blob/1c271570ac83aeb6aa8e7ff25449f3299b0d2e53/metadata/koniq10k_distributions_sets.csv)

The seven raw predictors are brightness, root mean square contrast, colorfulness, sharpness, JPEG quality factor, bitrate and original image area in pixels. The first four measure visual attributes. The other three describe the source image and its encoding. None contains this image’s quality grades. The source authors used preliminary subjective studies to choose some indicator types, then sampled a diverse image collection using visual attributes and image content. The adapter omits the eighth field, a categorical content-cluster ID taking 200 values, and excludes all human-derived fields from the model input. This low-dimensional judge has access to measured image attributes only. [Study sections 3.4 and 3.5](https://arxiv.org/pdf/1910.06180)

**Annotation cost and population.** The journal article reports 2,302 participating CrowdFlower workers, of whom 1,459 passed all screening stages. A separate group of 11 professional photographers helped establish the screening questions. One worker filter removed contributors whose Pearson correlation to preliminary crowd MOS was below 0.5. This matters when interpreting CE-versus-Pearson results against the released grades. The journal article describes more than 1.2 million trusted judgments. All counts and budget units in this experiment refer to the 1,078,154 votes actually present in the released histogram file. The earlier paper, journal article, authors’ database page and DaRUS release provide no monetary payment per KonIQ vote or full collection expenditure that we could verify. Report measured cost in votes and distinguish any assumed dollar conversion. [Journal article, section 4](https://arxiv.org/pdf/1910.06180) · [Earlier dataset paper](https://arxiv.org/pdf/1803.08489) · [Authors’ database page](https://database.mmsp-kn.de/koniq-10k-database.html)
