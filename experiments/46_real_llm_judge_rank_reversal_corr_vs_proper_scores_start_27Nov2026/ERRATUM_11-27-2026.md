# Erratum to the Experiment 46 README (11-27-2026)

**Doc link:** <https://github.com/brando90/judges-dont-need-psychometrics-or-corr/blob/main/experiments/46_real_llm_judge_rank_reversal_corr_vs_proper_scores_start_27Nov2026/ERRATUM_11-27-2026.md>

**TLDR:** README item 1 says "H1 is supported". Under the frozen wording of H1 it is not: H1 is about Pearson, and no Pearson reversal is significant at the frozen B = 4,000. The two significant reversals are Spearman. No result file changes; read README item 1 together with this note.

1. **What the README says.** Item 1 of the TLDR list: "H1 is supported: two significant rank reversals", citing GPT-6 Astra against GLM 5.3 on Spearman (SNLI +0.021, MNLI +0.034) versus Brier skill.
2. **What was frozen.** `PROTOCOL.md` (commit 83b9782, 11-27-2026 19:05 -0800, before the analysis scripts and results), line 54: "H1 (primary). At least one significant rank reversal between Pearson and the primary proper score exists in at least one set of the frontier panel or the local panel." H2 is the same for top-1 agreement or kappa. Spearman is named in neither.
3. **What the frozen run shows** (`results/summary.json`, B = 4,000). Significant reversals against the primary proper score, listed as Pearson / Spearman / top-1 / kappa. Frontier panel, 50 comparisons: 0 / 2 / 0 / 0. Local-plus-frontier panel, 140 comparisons: 0 / 0 / 0 / 0. So H1 as frozen is not supported, and H2 is not supported. The two Spearman reversals (Holm-adjusted p 0.025 and 0.042) are real; Spearman was not the frozen primary endpoint.
4. **A sensitivity run outside the protocol** (`results_B20000/`, commit 6f500c3, B = 20,000, labeled a deviation in that commit). The frontier panel is unchanged (0 / 2 / 0 / 0). The 140-comparison panel has one significant Pearson reversal: ChaosNLI MNLI-m, `qwen2.5-0.5b|native` versus `qwen2.5-0.5b|verbalized`, two readouts of the same small model (Holm-adjusted p 0.040 for the correlation difference and 0.014 for the primary-score difference; at B = 4,000 the larger of the two is 0.070). This does not replace the frozen verdict. It is recorded here so the verdict is not read as insensitive to the resampling budget in the local panel.
5. **Corrected reading of README item 1.** No Pearson reversal is significant at the frozen B = 4,000, so H1 is not supported. Two Spearman reversals are significant: GPT-6 Astra beats GLM 5.3 on Spearman on SNLI and MNLI-m while having significantly lower Brier skill.
6. **Where this was checked.** `docs/notes/blog_support_27Nov2026/blog_numbers_check.py`, claims R1, R1b and R3b, which re-derive items 3 and 4 from `results/` and `results_B20000/` (PASS in two identical runs).
