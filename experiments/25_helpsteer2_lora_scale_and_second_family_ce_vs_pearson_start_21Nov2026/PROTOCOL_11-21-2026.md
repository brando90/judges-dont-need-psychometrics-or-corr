**TLDR:** Pre-registered protocol for Experiment 25 testing (A) whether cross-entropy (CE) low-rank adaptation (LoRA) weight training clears Pearson LoRA training under strict two-way crossed (`draw x prompt`) simultaneous 95% bands on `Qwen/Qwen3-4B-Instruct-2507` when scaling to `20` draws and `B_total = 8,192` (`N_train = 4,096`), and (B) whether the CE-over-Pearson threshold replicates on a second open-weight architecture (`unsloth/Llama-3.1-8B-Instruct`).

## 1. Motivation and Research Questions

In [`experiments/24_trained_open_weight_judge_helpsteer2_ce_vs_pearson_start_21Nov2026/`](../24_trained_open_weight_judge_helpsteer2_ce_vs_pearson_start_21Nov2026/RESULTS_11-21-2026.md), calibrated CE-trained LoRA of `Qwen/Qwen3-4B-Instruct-2507` beat calibrated Pearson-trained LoRA on held-out normalized individual-rating **ranked probability score (RPS)** under conditional-on-draw simultaneous 95% bands from `B_total = 512 (N_train = 256)` onward (`9/10` draws at `B_total = 2,048`; `10/10` draws on CE and total variation distance [TVD] with crossed `p-val <= 0.0232`), while two-way crossed (`draw x prompt`) simultaneous 95% RPS sat at `[-0.00031, +0.00250]` (crossing `0` by `0.00031`). Experiment 25 isolates two follow-up questions under the same matched-budget methodology, committed and hashed **before** any Study A or Study B training or test evaluation:

1. **Study A (Scale & Draw Power on `Qwen/Qwen3-4B-Instruct-2507`):** Expanding to `S = 20` nested draws and budgets `B_total in {512, 1024, 2048, 4096, 8192}` (`N_train in {256, 512, 1024, 2048, 4096}`), does calibrated CE LoRA surpass calibrated Pearson LoRA under two-way crossed (`draw x prompt`) simultaneous 95% RPS intervals, and where does it plateau relative to the leave-one-vote-out human reference (`0.14567`)?
2. **Study B (Second-Family Replication on `unsloth/Llama-3.1-8B-Instruct`):** Using the identical prompt-disjoint pools (`train_pool=1,600`, `val_pool=800`, `cal_pool=800`, `test_set=1,038`), `S = 10` nested draws, and `B_total in {16, 32, 64, 128, 256, 512, 1024, 2048}` from Experiment 24, does the calibrated CE-over-Pearson threshold hold on an independent transformer family (`LlamaForCausalLM`)?

## 2. Dataset, Disjoint Pools, and Master Bundle

- **Source release:** `nvidia/HelpSteer2` (`990b2711a36180dd19d9c94b8627844866f8982a`), `helpfulness` votes `r in {0, 1, 2, 3, 4}` (`K = 5`), prepared in `results/data_manifest.json` (`prepared_bundle_sha256` = `1f7046e0441a532aefd8c2fd4afd24de5faa5a82f1e261d1ac3096120d28a814`):
  - **Sealed held-out test set ($S_{\text{test}}$):** All `1,038` responses across `519` unique source prompts in official `validation.jsonl.gz` (`3,610` votes; leave-one-vote-out human reference RPS = `0.14567`, CE = `1.3585` nats). Zero prompt overlap with official `train.jsonl.gz`.
  - **Deterministic prompt order (`train.jsonl.gz`, `10,161` unique prompts):** Ranked identically by `SHA-256("exp24-prompt|" + prompt)` with 1 deterministically selected response per prompt:
    - **Study A (`qwen3_4b`):** `train_pool` = ranks `[0:4096]` (`4,096` prompts), `val_pool` = `[4096:6144]` (`2,048` prompts), `cal_pool` = `[6144:8192]` (`2,048` prompts), `S = 20` draws (`SeedSequence([20261121, 25, draw_id])`), budgets `B_total in [512, 1024, 2048, 4096, 8192]`.
    - **Study B (`llama31_8b`):** `train_pool` = ranks `[0:1600]`, `val_pool` = `[1600:2400]`, `cal_pool` = `[2400:3200]`, `S = 10` draws (`SeedSequence([20261121, 24, draw_id])`), budgets `B_total in [16, 32, 64, 128, 256, 512, 1024, 2048]` (`d = 1` rating per item). Within each study, all four splits have pairwise zero prompt overlap.

## 3. Backbones, Chat Rendering, Left-Padded Batching, and Matched Training

- **Backbone snapshots (`/dfs/scratch0/brando9/at1025_hf/hub`):**
  - **Study A:** `Qwen/Qwen3-4B-Instruct-2507` (`36` layers, `hidden_size = 2560`, frozen layers `0..31`, LoRA on top `4` blocks `32..35` + `5`-logit head = `1,847,813` trainable parameters).
  - **Study B:** `unsloth/Llama-3.1-8B-Instruct` (`LlamaForCausalLM`, `32` layers, `hidden_size = 4096`, frozen layers `0..27`, LoRA `rank = 8`, `alpha = 16.0` on all `7` linear projections `q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj` across top `4` blocks `28..31` + `float32` `5`-logit rating head initialized from `lm_head` digit tokens `["0","1","2","3","4"]` = `3,428,357` trainable parameters).
- **Prompt & trailing-space invariance:** Same XML-delimited rubric (`<user_prompt>`, `<assistant_response>`, `enable_thinking=False` for `qwen3_4b` only, `continue_final_message=True`, `max_seq_len = 4096`, ending with `"Helpfulness grade (0-4): "`). Because `Llama-3.1-8B-Instruct`'s tokenizer template trims trailing whitespace on `continue_final_message=True`, the renderer explicitly preserves the single trailing space before tokenization so the next token immediately aligns with digits `0..4`.
- **Length-grouped left-padded mini-batch equivalence:** Training & validation passes sort sequences by token length into micro-chunks of up to `8` left-padded sequences using an explicit 4D `bfloat16` causal mask (`-inf` off invalid keys, `0.0` on valid causal keys and pad self-diagonals `r == c` so masked pad queries produce finite softmax derivatives). Exact numerical agreement between full-model forward/backprop and batched left-padded cached-`H^(split)` forward/backprop (`SDPBackend.MATH`, `< 1e-5` prob diff) and Epoch-0 Karpathy sanity controls (`label_in_prompt >= 4/5`, `blank_response < 1.2`, `matched_r > shuffled_r`, 1-batch 40-step overfit) are verified for both architectures before any feature extraction or training run.
- **Optimization & checkpoint selection:** Identical across CE and Pearson conditions (`AdamW`, `weight_decay = 0.01`, `grad_clip = 1.0`, mini-batch `M = min(N_train, 32)`, `lr in {5e-5, 2e-4, 8e-4}`, `4` validation checkpoints at `{0.25, 0.50, 0.75, 1.00} * T(N_train)`, selecting by minimum validation RPS on `S_val`). Total steps `T(N_train) = max(16, min(cap, 6 * ceil(N_train / 32)))` with `cap = 256` for Study A (`N_train <= 4,096`) and `cap = 160` for Study B (`N_train <= 1,024`).

## 4. Matched Post-Hoc Calibration, Metrics, and Uncertainty

Identical to [`experiments/24_trained_open_weight_judge_helpsteer2_ce_vs_pearson_start_21Nov2026/PROTOCOL_11-21-2026.md`](../24_trained_open_weight_judge_helpsteer2_ce_vs_pearson_start_21Nov2026/PROTOCOL_11-21-2026.md) §§ 5–6: `S_cal`-fitted 7-parameter strictly convex L-BFGS-B calibrator (4-fold CV ridge) plus Experiment 23 1D 4-bin sensitivity, compared against `uniform`, `training_histogram`, `all_dev_histogram`, `base_calibrated_matched` (`N_cal`), and `base_calibrated_all_dev` (`B_total`). Primary metric: held-out normalized individual-rating RPS (`0–1`, lower is better). Secondary metrics: CE (`6e-6` and `1e-2` floors, nats), TVD (`2–5` vote sparse-histogram diagnostic), multiclass Brier, Pearson `r`, Spearman `rho`, Kendall `tau-b`, Lin's concordance correlation coefficient (CCC), signed bias, mean absolute error (MAE), cumulative expected calibration error (ECE), modal agreement, and within-prompt pair accuracy. Uncertainty: `4,000` prompt-clustered bootstrap draws (`seed = 20261125`), reporting conditional simultaneous max-`t` 95% intervals and two-way crossed (`draw x prompt`) pointwise and simultaneous 95% intervals, plus step-down threshold `N*` and any budget favoring Pearson.
