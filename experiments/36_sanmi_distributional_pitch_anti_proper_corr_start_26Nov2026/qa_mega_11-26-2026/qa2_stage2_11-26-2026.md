## Major Issues Found and Fixed

1. **M1 — Inverted heatmap colormap & invisible `inf` cell labels (`make_figures.py`, `_matrix`):**
   - **Finding:** `wrong_objective_matrix.png` and `wrong_objective_matrix_popquorn_veribench.png` used `cmap="viridis_r"` while the title stated `"color is within-column rank (darker is better)"` and the colorbar read `"Rank in column (0 = best)"`. Because `viridis_r` maps `0` to bright yellow and `4` to dark purple, the best rows appeared bright yellow and worst rows appeared dark purple; additionally, `mse-trained head` `cross-entropy (nats)` cells (`rank = NaN`, `"inf"`) rendered white text on a white background, making `"inf"` completely invisible.
   - **Fix:** Switched to `cmap="viridis"`, set `ink = "black" if (not np.isfinite(rank[i, j]) or rank[i, j] >= midpoint) else "white"`, and added explicit x/y axis labels (`Held-out test metric (proper scores: lower better; correlations: higher better)` and `Training objective (linear head)`).

2. **M2 — Missing `M1`, `M5`, `M20` bars in `single_pass_vs_rollout.png` (`make_figures.py`, `_rollout`):**
   - **Finding:** `_rollout` plotted `r["ce"]`, which is `"inf"` for `M1`, `M5`, and `M20` (because one unfloored Monte Carlo draw puts zero probability on a realized rating), leaving 3 blank columns on `single_pass_vs_rollout.png` while `SANMI_PITCH.md` and `RESULTS_SUMMARY.md` report the 8-rep floored Monte Carlo means (`9.6059`, `3.9603`, `1.7095`).
   - **Fix:** Plotted `r.get("ce_mean_over_reps", r["ce"])` with value annotations (`1.210`, `9.606`, `3.960`, `1.710`), y-axis headroom, and explicit title `"Single linear pass vs M multinomial samples (1e-6 floor on MC histograms)"`.

3. **M3 — Matplotlib mathtext mangling (`0.05overexpert5`), x-label collisions, and stray `3 x 10^0` minor ticks (`make_figures.py`, `_plot_curve`, `_dollar_axis`):**
   - **Finding:** Unescaped `$` signs in `"Ratings per item k. Each top tick is crowd $0.05 over expert $5. Test uses every test rating."` triggered Matplotlib TeX math mode, rendering `0.05overexpert5` and overflowing into adjacent subplots in all 3 crossover PNGs; narrow log-scale spans on the top dollar axis also printed a stray `3 x 10^0` minor label.
   - **Fix:** Replaced with a two-line label using `USD 0.05 crowd / USD 5 expert` and added `top.xaxis.set_minor_formatter(NullFormatter())`.

4. **M4 — Unpinned SHA-256s for TTJ `native_main` & CertJudge sibling reads and unsafe fallback (`data_io.py`):**
   - **Finding:** `load_veribench_fsc_native_main` and `load_certjudge_real_panels` relied on `git show <rev>:<path>` without verifying SHA-256 digests, and `_resolve_sibling_text` / `_fetch_text_cached` would accept unverified working-tree files or cached URL files when `git show` was unavailable (note: all 3 sibling checkouts on disk have dirty working trees and/or HEADs ahead of the pinned commits).
   - **Fix:** Added `TTJ_MANIFEST_SHA`, `TTJ_PACKET_TREE_SHA`, per-entry `entry["sha256"]` checks, and `CERTJUDGE_SHAS`; enforced `expected_sha` verification in `_resolve_sibling_text` (rejecting dirty/tampered local files and mismatches) and `_fetch_text_cached`.
